---
openapi: delete /partner-tags/{partnerTagId}/partners
sidebarTitle: "Remove a tag from partners"
---

<Tip>
  Identify partners by `partnerIds` or by `tenantIds` (your own internal IDs),
  but not both. Each call accepts 1 to 100 partners. The response's `count` is
  the number of partners the tag was removed from, so partners that don't have
  the tag are not counted.
</Tip>
