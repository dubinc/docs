Webhooks send real-time notifications when events happen in your Dub workspace. All webhook payloads follow this structure:

```json webhook-payload.json
{
  "id": "evt_KleiO4HBwZFbO1vZLWIPZ2AtX",
  "event": "link.created",
  "createdAt": "2024-08-26T16:41:52.346Z",
  "data": {}
}
```

- **id** – Unique event ID
- **event** – Event type (e.g. `link.created`)
- **createdAt** – ISO 8601 timestamp when the event was created
- **data** – Event-specific payload

## Dub Partners

Here are the webhook events that are available for [Dub Partners](https://dub.co/partners):

| Event Type                                                                             | Description                                                                                                                                   |
| -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| [`partner.enrolled`](/docs/webhooks/events/partner-enrolled)                           | Occurs whenever a **partner is enrolled** in your program (either their application was approved, they accepted your invite, or via the API). |
| [`partner.application_submitted`](/docs/webhooks/events/partner-application-submitted) | Occurs whenever a **partner submits an application** to your program.                                                                         |
| [`partner.merged`](/docs/webhooks/events/partner-merged)                               | Occurs when **two partner accounts are merged**.                                                                                              |
| [`lead.created`](/docs/webhooks/events/lead-created)                                   | Occurs whenever a **lead is created**.                                                                                                        |
| [`sale.created`](/docs/webhooks/events/sale-created)                                   | Occurs whenever a **sale is created**.                                                                                                        |
| [`commission.created`](/docs/webhooks/events/commission-created)                       | Occurs whenever a **commission is created** for a partner (clawbacks will also trigger this event with a negative amount).                    |
| [`discount_code.created`](/docs/webhooks/events/discount-code-created)                 | Occurs whenever a **discount code is created** for a partner.                                                                                 |
| [`discount_code.deleted`](/docs/webhooks/events/discount-code-deleted)                 | Occurs whenever a **discount code** for a partner is deleted.                                                                                 |

## Dub Links

Here are the webhook events that are available for [Dub Links](https://dub.co/links):

| Event Type                                           | Description                            |
| ---------------------------------------------------- | -------------------------------------- |
| [`link.created`](/docs/webhooks/events/link-created) | Occurs whenever a **link is created**. |
| [`link.updated`](/docs/webhooks/events/link-updated) | Occurs whenever a **link is updated**. |
| [`link.deleted`](/docs/webhooks/events/link-deleted) | Occurs whenever a **link is deleted**. |
| [`link.clicked`](/docs/webhooks/events/link-clicked) | Occurs whenever a **link is clicked**. |
