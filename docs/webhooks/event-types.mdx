Webhooks send real-time notifications when events happen in your Dub workspace. All webhook payloads follow this structure:

```json webhook-payload.json
{
  "id": "evt_KleiO4HBwZFbO1vZLWIPZ2AtX",
  "event": "link.created",
  "createdAt": "2024-08-26T16:41:52.346Z",
  "data": {}
}
```

- **id** – Unique event ID
- **event** – Event type (e.g. `link.created`)
- **createdAt** – ISO 8601 timestamp when the event was created
- **data** – Event-specific payload

## Dub Partners

[Dub Partners](https://dub.co/partners) lets you run a partner program with referral links, commissions, and payouts. Here are the webhook events that are available for Dub Partners:

| Event Type                                                                             | Description                                                                                                                                                                                                                                    |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`partner.application_submitted`](/docs/webhooks/events/partner-application-submitted) | Occurs whenever a [partner submits an application](/docs/api-reference/partners/applications) to your program.                                                                                                                                 |
| [`partner.enrolled`](/docs/webhooks/events/partner-enrolled)                           | Occurs whenever a [partner is enrolled](/docs/api-reference/partners/create) in your program (either their application was approved, they accepted your invite, or via the API).                                                               |
| [`partner.merged`](/docs/webhooks/events/partner-merged)                               | Occurs when two [partner](/docs/api-reference/partners/list) accounts are merged.                                                                                                                                                              |
| [`lead.created`](/docs/webhooks/events/lead-created)                                   | Occurs whenever a [lead is created](/docs/api-reference/track/lead).                                                                                                                                                                           |
| [`sale.created`](/docs/webhooks/events/sale-created)                                   | Occurs whenever a [sale is created](/docs/api-reference/track/sale).                                                                                                                                                                           |
| [`commission.created`](/docs/webhooks/events/commission-created)                       | Occurs whenever a [commission is created](/docs/api-reference/commissions/list) for a partner (clawbacks will also trigger this event with a negative amount).                                                                                 |
| [`bounty.created`](/docs/api-reference/bounties/list)                                  | Occurs whenever a [bounty](/docs/api-reference/bounties/list) is created in your program.                                                                                                                                                      |
| [`bounty.updated`](/docs/api-reference/bounties/list)                                  | Occurs whenever a [bounty](/docs/api-reference/bounties/list) in your program is updated.                                                                                                                                                      |
| [`payout.confirmed`](/docs/webhooks/events/payout-confirmed)                           | Occurs whenever a [payout](/docs/api-reference/payouts/list) in your program is confirmed.                                                                                                                                                     |
| [`discount_code.created`](/docs/webhooks/events/discount-code-created)                 | Occurs whenever a [discount code is created](/docs/api-reference/discount-codes/create) for a partner.                                                                                                                                         |
| [`discount_code.deleted`](/docs/webhooks/events/discount-code-deleted)                 | Occurs whenever a [discount code](/docs/api-reference/discount-codes/list) for a partner is deleted.                                                                                                                                           |

## Dub Links

[Dub Links](https://dub.co/links) is your short link and analytics platform for creating, managing, and tracking links. Here are the webhook events that are available for Dub Links:

| Event Type                                           | Description                                                                                          |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| [`link.created`](/docs/webhooks/events/link-created) | Occurs whenever a [link is created](/docs/api-reference/links/create) in your workspace.             |
| [`link.updated`](/docs/webhooks/events/link-updated) | Occurs whenever a [link is updated](/docs/api-reference/links/update) in your workspace.             |
| [`link.deleted`](/docs/webhooks/events/link-deleted) | Occurs whenever a [link is deleted](/docs/api-reference/links/delete) in your workspace.             |
| [`link.clicked`](/docs/webhooks/events/link-clicked) | Occurs whenever a [link](/docs/api-reference/links/list) is clicked by a user.                       |
