Another feature of the Dub Analytics script is the ability to [track conversion events on the client-side](/docs/quickstart/client).

This is useful for cases where you don't have access to your server-side code, such as when you're using a third-party service like [Google Tag Manager](/docs/integrations/google-tag-manager).

In this guide, we'll learn how to set up client-side conversion tracking with the Dub Analytics script.
